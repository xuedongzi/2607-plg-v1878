# 毗陵吕氏族谱 电子版 / Piling Lv Clan Genealogy Digital Edition

> 开源 · 可检索 · 全球共享  
> Open Source · Searchable · Global Access

## 简介 / About
本仓库旨在将《毗陵吕氏族谱》数字化并开源发布，帮助中英文读者、宗亲与研究者共同查阅、校对、补录与续修。
This repository publishes the Piling Lv Clan genealogy as an open-source digital project, inviting Chinese and English readers, descendants, and researchers to read, verify, contribute, and preserve the lineage together.

## 目标 / Goals
- 发布《毗陵吕氏族谱》核心谱系内容，面向全球吕氏宗亲。
- 在中文版与英文版之间并列呈现，便于中英双语读者共同参与。
- 将研究、修谱、补录与合作过程公开透明，鼓励基于事实的贡献。
- 通过清晰的 `.gitignore` 规则，保留后续工作与分支线索，但不将备份、草稿、私人内容写入公开仓库。

## 参与方式 / How to Contribute
欢迎所有宗亲与研究者参与：
1. 提交 Issue：补充世系信息，指出错漏，建议结构改进。
2. 提交 Pull Request：修正文本、补充注释、添加翻译或改善目录。
3. 提供资料：上传老谱页、老照片、家族口述史等可公开分享的资料。
4. 参与讨论：在 Issue 或 Discussions 中交流分支关系、修谱方法和来源。

We welcome contributions from clan members and researchers:
1. Open an issue to add lineage details, fix mistakes, or suggest structural improvements.
2. Open a pull request to correct text, add notes, improve translations, or update the index.
3. Share public historical material, such as scans, photos, or oral history references.
4. Join discussions about branch connections, research methods, and sources.

## 项目流程 / Project Workflow
- 公开内容：主要谱系文本、目录、世系表和说明性文字。
- 忽略内容：`90-private/`, `99-archive/`, `10-history/`, `80-postcript/`, `88-research/` 等后续工作与草稿。
- 版本管理：建议使用 `main` 分支作为公开发布分支，创建分支进行不同修订，再通过 PR 合并。
- 翻译协作：中文与英文内容可并行更新，鼓励先写中文说明，再补充英文摘要。

## 社区规范 / Community Guide
- 保持尊重与包容，欢迎不同观点，但禁止攻击、骚扰或无礼行为。
- 提交内容请尽量注明来源和依据，避免传播未经验证的个人信息。
- 代码、格式与翻译改动请保持清晰，方便他人审阅。

为什么选择 `CC BY-SA 4.0`：

Why choose `CC BY-SA 4.0`:

- It requires derivatives to remain open under the same terms.
- It avoids `NC` restrictions that can limit genuine open-source collaboration.
