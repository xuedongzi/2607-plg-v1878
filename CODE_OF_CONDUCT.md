# 行为守则 / Code of Conduct

## 我们的承诺 / Our Pledge

为了营造一个开放、包容、尊重的族谱社区，我们希望每个人都遵守本行为守则。  
In order to foster an open, inclusive, and respectful genealogy community, we expect everyone to follow this code of conduct.

## 期待行为 / Expected Behavior

- 对所有贡献者保持尊重与礼貌。  
  Be respectful and courteous to all contributors.
- 假定他人贡献出于善意。  
  Assume good faith in others' contributions.
- 让讨论专注于项目和族谱内容。  
  Keep discussions focused on the project and genealogy.
- 接受反馈并保持建设性。  
  Be open to feedback and constructive criticism.

## 不可接受的行为 / Unacceptable Behavior

- 骚扰、侮辱或辱骂性语言。  
  Harassment, insults, or abusive language.
- 人身攻击、歧视或仇恨言论。  
  Personal attacks, discrimination, or hate speech.
- 故意破坏项目讨论或工作流程。  
  Deliberate disruption of project discussion or workflow.
- 未经同意共享私人个人信息。  
  Sharing private personal information without consent.

## 举报 / Reporting

如果您遇到或目击不可接受行为，请开一个 Issue 或直接联系仓库维护者。  
If you experience or witness unacceptable behavior, please open an issue or contact the repository maintainers directly.
