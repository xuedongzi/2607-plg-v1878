# 贡献指南 / Contributing to 毗陵吕氏族谱 / Piling Lv Clan Genealogy

感谢您对本族谱数字化项目的关注与支持。  
Thank you for your interest in contributing to this genealogy digitization project.

本项目希望构建一个清晰、中英双语、开放的族谱参考资料，便于宗亲与研究者共同参与。  
Our goal is to build a clean, bilingual, and open genealogy reference for clan members and researchers.

## 如何贡献 / How to contribute

1. 叉出仓库（若使用 GitHub）或在有写权限时直接克隆。  
   Fork the repository (if using GitHub), or clone directly if you have write access.
2. 为本次修改创建新分支。  
   Create a new branch for your change.
   - 示例 / Example: `git checkout -b fix-typo-in-geneagram`
3. 在 Markdown 文件中编辑内容，或在现有目录下添加资料。  
   Make your edits in Markdown files, or add materials under existing directories.
4. 以清晰的提交信息提交。  
   Commit with a clear message.
   - 示例 / Example: `git commit -m "修正吕氏世系表中的错别字 / Fix typo in geneagram"`
5. 推送分支并发起 Pull Request。  
   Push your branch and open a Pull Request.

## 可以贡献的内容 / What to contribute

- 修正或补充族谱条目。  
  Corrections or clarifications to genealogy entries.
- 提供更多参考资料或文献来源。  
  Additional references or document sources.
- 完善中英文翻译与说明。  
  Better Chinese/English translations or explanations.
- 改进目录结构与导航体验。  
  Improvements to the index and navigation.
- 优化项目文档。  
  Project documentation enhancements.

## 指南 / Guidelines

- 保持贡献内容事实清晰、表达尊重。  
  Keep contributions factual and respectful.
- 尽量注明来源。  
  Cite sources when possible.
- 避免在公开文件中添加现代在世成员的私人信息。  
  Avoid adding private living-member data to public files.
- 让改动保持简洁、易于审阅。  
  Keep changes focused and easy to review.

## 讨论 / Discussion

如果您想提出较大的修改建议，请先开一个 Issue。  
If you want to propose a bigger change, open an issue first.

这样可以让维护者和其他贡献者在提交 PR 前讨论范围与方向。  
This helps maintainers and contributors discuss scope before a full PR.
